# 심리상담 에이전트

AI 기반 심리상담 챗봇 에이전트입니다. Anthropic Claude API를 활용하여 공감적이고 전문적인 심리상담 대화를 제공합니다.

## 주요 기능

- **공감적 대화**: 적극적 경청, 감정 인정, 개방형 질문 등 전문 상담 기법 적용
- **단계별 상담 진행**: 도입 → 탐색 → 이해 → 통합 → 마무리 5단계 자동 전환
- **위기 감지**: 자살/자해 관련 키워드 감지 시 즉각적인 위기 대응 및 전문 기관 안내
- **세션 관리**: 대화 기록 저장/불러오기 지원
- **인지적 재구성**: 부정적 사고 패턴을 새로운 관점에서 바라볼 수 있도록 지원

## 상담 기법

| 기법 | 설명 |
|------|------|
| 적극적 경청 | 내담자의 말을 반영하여 되돌려줌 |
| 감정 인정 | 감정을 있는 그대로 수용 |
| 개방형 질문 | 깊은 탐색을 유도하는 질문 |
| 인지적 재구성 | 부정적 사고 패턴 전환 |
| 요약 및 정리 | 대화 내용 정리 |
| 그라운딩 | 불안/공황 완화 기법 |
| 강점 기반 접근 | 내담자의 강점 발견 및 강화 |

## 설치

```bash
pip install -r requirements.txt
```

## 환경 설정

Anthropic API 키가 필요합니다:

```bash
export ANTHROPIC_API_KEY="your-api-key"
```

## 실행

```bash
python -m psych_counselor.main
```

### 옵션

```bash
python -m psych_counselor.main --model claude-sonnet-4-6   # 모델 지정
python -m psych_counselor.main --save-dir ./my_sessions      # 저장 경로 지정
```

### 대화 중 명령어

| 명령어 | 설명 |
|--------|------|
| `quit` / `exit` / `종료` | 상담 종료 |
| `save` | 현재 세션 저장 |
| `status` | 세션 정보 확인 |

## 프로젝트 구조

```
psych_counselor/
├── __init__.py        # 패키지 초기화
├── agent.py           # 핵심 에이전트 로직 (Claude API 연동)
├── conversation.py    # 대화 세션 관리
├── main.py            # CLI 인터페이스
├── prompts.py         # 시스템 프롬프트 및 템플릿
└── techniques.py      # 상담 기법 및 위기 감지
```

## 주의사항

이 서비스는 AI 기반 심리상담 보조 도구이며, 전문 심리상담을 대체하지 않습니다.
